# File Explorer Pro

Native Android file reader and analyzer built with Kotlin.

## Languages
- Arabic (RTL)
- English (LTR)
- Follow system language

The selected app language is managed through AndroidX per-app locales and is retained by the system.

## First milestone
- Bilingual native interface and language settings
- Android Storage Access Framework file picker
- Basic file metadata and text preview

More file formats and binary analysis will be added in later milestones.
